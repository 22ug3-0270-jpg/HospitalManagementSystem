## Project Description
A Java-based Hospital Management System that demonstrates the use of four fundamental data structures:
1. **Binary Search Tree (BST)** - Patient Records
2. **Queue** - Emergency Patient Management
3. **Stack** - Treatment History
4. **Singly Linked List** - Patient Visit History

## Features

### 1. Patient Records (BST)
- Insert new patient
- Search patient by ID
- Delete patient
- In-order traversal (ascending order of Patient ID)

### 2. Emergency Patient Queue (Queue)
- Enqueue patient
- Dequeue patient (FIFO)
- Display waiting patients
- Empty queue handling

### 3. Treatment History (Stack)
- Push completed treatment
- Pop most recent treatment (LIFO)
- Display all treatments
- Empty stack handling

### 4. Patient Visit History (Singly Linked List)
- Add new visit
- Remove visit
- Search visit
- Display all visits
